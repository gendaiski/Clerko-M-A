# Clerko M&A

M&A marketplace platform for Bahrain and the GCC, connecting business sellers and buyers.

## Prototype

The interactive prototype that the platform build works from is
[`prototype/clerko-ma-site.html`](prototype/clerko-ma-site.html). Open it in a browser. It is a
single self-contained file with 19 views: marketing pages, the seller and buyer journeys, the
Deal Room with the Clerko Agent, escrow (deferred), the user workspace and the admin console.

Source: Dropbox `/Wireframes/The Law Tech Labs/Ventures/clerko-ma/` (version of 22 Jul 2026).
See [`prototype/README.md`](prototype/README.md) and
[`prototype/clerko-m-a-RECORD.md`](prototype/clerko-m-a-RECORD.md) for the project notes.
